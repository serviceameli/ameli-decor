# Публикация через ZIP

Панель ameli-rental.ru принимает до 25 МБ в ZIP, до 50 МБ после распаковки и до 500 файлов. Полная сборка от 25.09.2026 содержит 682 файла и не подходит по числу файлов.

## Вариант с отдельным хранением фотографий

`npm run package:hosting` создаёт `release/ameli-decor.zip` и файл с результатами проверки `release/ameli-decor.json`. Нужны Node.js и Python 3; дополнительные Python-библиотеки не требуются.

Архив содержит HTML, CSS, JavaScript, данные, шрифты и библиотеку PDF. Все фотографии и их превью загружаются с существующего https://serviceameli.github.io/ameli-decor/. Их качество, количество, кадрирование и порядок не меняются. Локальные ссылки остаются относительными; внешними становятся только адреса фотографий.

Сборщик проверяет, что данные уже опубликованы на хранилище фотографий, проверяет разрешение CORS на образце фотографии для PDF и лимиты ZIP. Расширения модулей в ZIP меняются с `.mjs` на `.js`, чтобы не зависеть от настройки MIME для `.mjs` на новом хостинге. Исходная сборка для GitHub Pages остаётся прежней.

## Первый запуск

1. В панели нажмите **Добавить**.
2. Укажите свободный поддомен, например `decor` (пример, доступность не проверена).
3. Для главной страницы оставьте URL-путь `/`. Для отдельного раздела можно указать `/promo`.
4. Выберите **ZIP с сайтом** и загрузите `ameli-decor.zip` целиком, не распаковывая.
5. Нажмите **Сохранить** и дождитесь статуса **Активен**.
6. Откройте выданный HTTPS-адрес в обычном браузере и на телефоне. Проверьте фотографии, выбор позиции, копирование заявки и **Мой PDF**. Проверку нужно повторить именно на новом домене: настройки панели и её политика внешних ресурсов пока не проверены.

## Обновления

1. Внести изменения в исходники/`content.json` и добавить фотографии в `assets/`.
2. Проверить изменения, опубликовать их в GitHub Pages и дождаться успешного развёртывания. Это размещает новые фотографии по доступным адресам.
3. Запустить `npm run package:hosting`. При несовпадении опубликованных данных сборка остановится, чтобы ZIP не ссылался на ещё не размещённые фотографии.
4. Сохранить предыдущий ZIP с датой как резервную копию.
5. В новой панели нажать **карандаш у существующего сайта**, загрузить новый ZIP и сохранить. Новый сайт создавать не нужно; адрес остаётся прежним.
6. Проверить результат на опубликованном адресе. Для возврата прошлой версии загрузить предыдущий ZIP; связанные фотографии должны оставаться на хранилище.

Обновление GitHub само по себе не обновляет сайт в ZIP-панели. Новый ZIP нужно загрузить отдельно. Можно поручать подготовку обновлений Codex: «Добавь эти позиции и подготовь ZIP для панели».

## Рост каталога и ограничения

Новые позиции и фотографии не расходуют лимит 500 файлов архива: в ZIP добавляются только записи внутри `content.json`. Размер этого файла постепенно растёт, но фотографии в ZIP не включаются. На 25.09.2026 ZIP занимает 634 920 байт, после распаковки — 1 510 566 байт, 12 файлов.

Сайт зависит от доступности GitHub Pages для посетителя. Нельзя удалять этот проект, отключать Pages или убирать используемые фотографии. Хранилище тоже имеет собственные лимиты, поэтому это не обещание неограниченного объёма. Если потребуется полностью уйти с GitHub, фотографии следует перенести в отдельное файловое хранилище/CDN с HTTPS и CORS для PDF либо увеличить лимиты панели. Другой совместимый адрес можно передать сборщику через `--images-base`.

## Что сохранено при переносе

- Форма подготавливает текст и PDF; клиент сам отправляет заявку менеджеру.
- При перезагрузке страницы сбрасываются выбранные позиции, палитра, все поля заявки и отметка дополнительных позиций; количество гостей возвращается к 40. Черновики больше не сохраняются в браузере.
- Сайт по-прежнему закрыт от индексации поисковиками (`noindex` и `robots.txt`). Это не ограничивает открытие по прямой ссылке и не является защитой доступа.

## Проверка 25.09.2026

12 тестов прошли. ZIP проверен на целостность и сохранение всех данных. В браузере проверены корень сайта и `/promo/`, экран 1280×720 и мобильный 390×844, карточка чёрной салфетки, выбор пяти разделов, копирование заявки и скачивание трёхстраничного PDF с внешними фотографиями. Все три страницы PDF отрисованы и просмотрены. Девять ссылок каталога и дополнительных позиций вернули HTTP 200. Публикация и HTTPS новой панели ещё не проверены.
