# Размещение сайта

Рабочий адрес: **https://setdecor.ameli-rental.ru/**.

Сайт размещён на существующем сервере Timeweb Cloud. Исходники находятся в
`serviceameli/ameli-decor`; изменения ветки `main` автоматически публикуются
через `.github/workflows/timeweb.yml`.

## Как обновлять

1. Изменить исходники, `content.json` или фотографии в `assets/`.
2. Сохранить изменения в Git и отправить в `main`.
3. В GitHub Actions дождаться зелёного **Publish setdecor to Timeweb**.
4. Проверить результат на рабочем адресе.

Workflow запускает `npm test`, затем `npm run build`, передаёт готовую `dist`
и проверяет опубликованную версию по HTTPS. Загружать ZIP в прежнюю панель
для этих обновлений больше не требуется.

## Файлы и HTTPS

HTML, CSS, JavaScript, данные, фотографии, превью, шрифты и библиотека PDF
находятся на Timeweb. Фотографии рабочей сборки загружаются с того же домена.
Сборка не зависит от доступности GitHub Pages для посетителя.

DNS поддомена: `setdecor.ameli-rental.ru A 217.149.19.37`.
Caddy обслуживает HTTPS; его данные сертификатов сохраняются при обновлениях.
Изменение основного домена, почты или других поддоменов для сайта не требуется.

На сервере сайт хранится отдельно от приложения Ameli OS:
`/srv/ameli-sites/setdecor`. Публикация статических файлов атомарно переключает
текущую версию и сохраняет предыдущую. Обычные обновления этого репозитория
не перезапускают портал или бота.

## Проверка и восстановление

Текущий Git SHA, номер запуска и SHA-256 манифеста доступны в
https://setdecor.ameli-rental.ru/setdecor-release.json.
Подробности ограниченного SSH-доступа и отката:
[`operations/TIMEWEB_DEPLOYMENT.md`](operations/TIMEWEB_DEPLOYMENT.md).

Резервная публикация GitHub Pages сохранена:
https://serviceameli.github.io/ameli-decor/index.html.
Собственный домен в настройках Pages не назначен.

Первая полная публикация на Timeweb проверена 19 ноября 2026 года:
https://github.com/serviceameli/ameli-decor/actions/runs/44551313801.

## Поведение сайта

- Форма подготавливает текст заявки и PDF; клиент отправляет заявку менеджеру.
- После перезагрузки выбор и поля формы сбрасываются, количество гостей — 40.
- Сайт сохраняет `noindex` и `robots.txt`. Это не защита доступа.
