# Ameli Rental · Декор под ключ

Отдельный закрытый прототип лендинга. Исходные генератор, калькулятор и лендинги в `../ameli_ready` не менялись.

## Обновление контента

В `content.json` хранятся девять пакетов, палитра, условия и все варианты оформления. В `packages[].price` указывается итоговая цена для организатора в рублях. Значение `null` означает «Цена уточняется». Цены из старого калькулятора сюда не переносились: состав нового пакета отличается.

Чтобы добавить фотографию, сохраните её в `assets/` с латинским именем и укажите путь в `image` нужного варианта. Добавьте `alt`. Для утверждённого варианта замените `draft: true` на `false`. Новые элементы можно добавлять в массивы `ceremony`, `tableCompositions`, `presidiumFlorals`, `presidiumBackdrops`, `napkins`. Лендинг и PDF подхватывают их из одного источника. Галереи PDF разбиваются на страницы по три изображения. При значительном расширении текстовых списков потребуется проверить их вёрстку в PDF.

Палитра и варианты без фотографий предварительные. Условия оплаты и доставки перенесены из `../ameli_ready/generator.html` (блоки `pageCompare` и `pageTerms`). Применение условий к новому пакету и итоговые цены нужно подтвердить до рассылки.

## Презентация

Окно скачивания содержит девять независимых цен для клиента. Они живут только в памяти страницы, не отправляются на сервер и не меняют `content.json`. Пустое поле экспортируется как «По запросу». Партнёрские цены не используются в PDF. В комплект включены только позиции из нового брифа, без номерков.

## Доступ

Закрытый доступ обеспечивает публикация Sites с доступом только владельцу. `noindex` и `robots.txt` сами по себе не являются защитой. Локальный сервер работает только на `127.0.0.1`. Для передачи организаторам нужно настроить аудиторию закрытого сайта. Прототип нельзя выдавать за уже доступный всем организаторам.

## Проверка и сборка

`npm test` проверяет количества и обработку цен. `npm run build` проверяет контент, существование изображений и собирает только публичные файлы в `dist/`. Внешних сетевых зависимостей на сайте нет: шрифты и PDF-библиотека локальные.

WebMCP: при наличии браузерного API регистрируется `download_decor_presentation`. Это тот же путь скачивания, что и в интерфейсе. В текущем окружении поддерживаемый контекст для проверки WebMCP не предоставлен; проверка регистрации не заявляется.
