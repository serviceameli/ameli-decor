# Ameli Rental · Готовые пакеты декора

Основной репозиторий: https://github.com/serviceameli/ameli-decor (закрытый). Все дальнейшие изменения сохраняются сюда. Старые генератор и калькулятор в `../ameli_ready` не менялись.

## Структура предложения

Первый экран сразу показывает четыре составляющие пакета с фотографиями и количествами. Переключатель на 20–100 гостей меняет только количества: одна зона церемонии, один президиум, одна композиция на стол из 10 гостей и одна салфетка на гостя. Ниже расположены четыре галереи:

1. Зона церемонии: готовые решения из каталога Ameli.
2. Зона президиума: арки и задники из раздела «Арки с драпировкой».
3. Композиции на стол: варианты без флористики из раздела готовых композиций.
4. Салфетки: фотографии из раздела текстиля.

Все 19 фотографий скачаны с `catalog.ameli-rental.ru`. Исходные URL, названия и дата получения перечислены в `catalog-sources.json`. Изображения сохранены локально, уменьшены без обрезки и подготовлены в JPEG для сайта и PDF. Отдельные цены аренды из каталога не выдаются за итоговые цены пакетов.

## Редактирование

`content.json` — общий источник для сайта и PDF. В `packages[].price` задаётся итоговая цена для организатора в рублях. Пока она не определена, используется `null` и отображается «Цена уточняется». Цены старого калькулятора не переносились: состав пакета другой.

Чтобы добавить фотографию, сохраните JPG в `assets/`, добавьте карточку в `ceremony`, `presidiumBackdrops`, `tableCompositions` или `napkins`. Обязательные поля: `id`, `title`, `description`, `image`, `alt`, `catalogName`, `sourceUrl`. Дополнительные варианты автоматически появляются в галерее и PDF. PDF делит галереи на страницы по шесть изображений.

20 оттенков палитры предварительные. Конкретное наличие ткани, ассортимент на дату, итоговые цены и применение условий доставки к этому пакету нужно подтвердить перед рассылкой.

## PDF

Скачивание содержит девять независимых цен для клиента. Они живут только в памяти страницы, не отправляются на сервер и не меняют `content.json`. Пустая цена экспортируется как «По запросу». Прайс организатора не используется в PDF. На столах — только варианты без флористики. Номерков нет.

## Запуск и проверка

- `npm run dev` запускает локальный просмотр.
- `npm run build` проверяет содержание и локальные изображения, затем собирает сайт в `dist/`.
- `npm test` проверяет количества и обработку цен.

Сайт не требует внешних библиотек в браузере: шрифты и PDF-библиотека включены в репозиторий.

## Доступ и размещение

Исходники находятся в закрытом GitHub-репозитории. GitHub Pages не включён: приватность исходников сама по себе не закрывает опубликованный сайт. Предыдущая версия в Sites остаётся отдельной публикацией, настройки находятся в `.openai/hosting.json`. Перенос на GitHub не меняет аудиторию старой публикации. `robots.txt` и `noindex` не являются защитой доступа.

WebMCP: при наличии браузерного API доступен `download_decor_presentation`, вызывающий тот же путь скачивания, что и интерфейс. Проверка в поддерживаемом WebMCP-контексте не заявляется.
